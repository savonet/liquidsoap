Module Liquidsoap_lang_data.Runtime_error

Errors raised while a script runs.

An error at runtime.

type runtime_error = private {
  1. kind : string;
  2. msg : string;
  3. pos : Liquidsoap_lang_prelude.Pos.t list;
  4. origin : string option;
}

origin is the OCaml exception the error was converted from, as text.

Register a function telling which other exceptions a script may catch, as the error kind and script positions it sees them with. They keep being reported as they are when nothing catches them.

val catchable : exn -> (string * Liquidsoap_lang_prelude.Pos.t list) option

The error kind and positions under which a script may catch exn, if any.

val notify : runtime_error -> unit

Run the on_error listeners on an error that is not raised.
