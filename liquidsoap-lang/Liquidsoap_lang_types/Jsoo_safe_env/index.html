Module Liquidsoap_lang_types.Jsoo_safe_env

Typing environments that js_of_ocaml can unmarshal.

type t

A typing environment without closures, marshalable without Marshal.Closures and therefore readable by js_of_ocaml. Custom types become constructors without parameters, named after the custom type, and only the language's own constraints survive restore.

type core_types = {
  1. source_methods : Type.t option;
  2. clock : Type.t option;
}

What a dump carries besides the environment: the types of what the language leaves to whoever links it, for a reader that has none.

val no_core_types : core_types
type restored = {
  1. restored_env : (string * Type.scheme) list;
  2. restored_core_types : core_types;
}
val strip : ?core_types:core_types -> (string * Type.scheme) list -> t
val restore : t -> restored
val abi_version : int

The dump format's version: a reader accepts the dumps written with the same one, whichever liquidsoap wrote them.

val to_string : version:string -> t -> string

Raises Invalid_argument if a closure is left. version is the liquidsoap that wrote the dump, which a reader that cannot read it names.

val of_string : string -> t

Raises Failure unless the dump was written in this abi_version, saying what wrote the one it was given.
