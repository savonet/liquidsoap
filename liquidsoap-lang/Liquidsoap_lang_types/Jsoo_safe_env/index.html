Module Liquidsoap_lang_types.Jsoo_safe_env

Typing environments that js_of_ocaml can unmarshal.

type t

A typing environment without closures, marshalable without Marshal.Closures and therefore readable by js_of_ocaml. Custom types become constructors without parameters, named after the custom type, and only the language's own constraints survive restore.

val strip : (string * Type.scheme) list -> t
val restore : t -> (string * Type.scheme) list
val to_string : version:string -> t -> string

Raises Invalid_argument if a closure is left.

val of_string : version:string -> string -> t

Raises Failure unless the dump was written by version.
