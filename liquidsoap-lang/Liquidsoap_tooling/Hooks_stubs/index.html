Module Liquidsoap_tooling.Hooks_stubs

Stand-ins for the hooks liquidsoap's core fills in, for the tools that link the language alone: what they cannot compute, a dump carries. A process that implements one of them keeps its own.

val install : core_types:Liquidsoap_lang_types.Jsoo_safe_env.core_types -> unit -> unit

core_types is what the dump carried of liquidsoap's own types.
