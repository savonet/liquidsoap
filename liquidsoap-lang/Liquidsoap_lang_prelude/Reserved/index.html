Module Liquidsoap_lang_prelude.Reserved

Names the language binds for its own use, out of scripts' reach.

Names the language binds for its own use. None of them can be lexed as a variable (see Lexer.is_var), so no script can define or shadow them.

val null : string

The module behind null.m and null(x).

val any : string

A value of any type, used by the reducer as a placeholder. Scripts spell it 💣, which they could also redefine.

val eval : string

The function behind let eval.

val json_parser : string

The parsers behind the let json.parse family.

val xml_parser : string
val yaml_parser : string
val sqlite_row_parser : string
val pattern_var : int -> string

Variables the reducer introduces to destructure a value, and to name the pattern arguments of %argsof.

val annotation_var : int -> string
