type hasher = {
  1. update : string -> int -> int -> unit;
  2. digest : unit -> int64;
}

A fast 64-bit hash over a stream of bytes: update s off len feeds a slice, digest () returns the hash of everything fed so far. The cache uses it to check its files, and reports every access as an error in a process with no implementation.

val build_id : (unit -> int64) t

A number that differs between builds of the running program, stable for the life of a process. The cache stamps it on every file, so an entry is only read back by the build that wrote it.
