Library duppy

The entry point of this library is the module: Duppy.

Library duppy.stdlib_utils

This library exposes the following toplevel modules:

  • Effect_utils
  • Signal_handlers Additive signal handlers, safe to register from any thread.
  • Thread_utils EINTR-safe wrappers around Thread functions. Each function retries automatically when interrupted by a signal, except wait_signal which returns on EINTR (any signal was received) and retries only on Sys_error "interrupted system call".
  • Unix_utils EINTR-safe wrappers around Unix I/O calls. Each function retries automatically when interrupted by a signal.
