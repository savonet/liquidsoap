Module Unix_utils

EINTR-safe wrappers around Unix I/O calls. Each function retries automatically when interrupted by a signal.

Create a pair of connected stream sockets, usable as a non-blocking wake-up channel with Unix.select on all platforms. Falls back to a loopback TCP pair on Windows systems without AF_UNIX support (pre-1803, Wine).
