# Findings

Defects, asymmetries and gaps found while writing the as-built spec. They are
kept out of the description and are the agenda for the normative pass.

**Checked** means reproduced by a run against a build of this tree (scratch
scripts, not committed). **Read only** means found by reading; a second read
should try to refute it before anything is built on it. Within each section,
ranked by data loss and security first, then correctness.

## Defects

| Id       | Finding                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Status                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| F-SRV-1  | **Path traversal.** The static handler behind `output.harbor.hls` URL-decodes the request path and joins it to the directory without normalising: `GET <path>/..%2F<file>` serves a file outside the HLS directory ([serving.md §3](serving.md#3-the-static-handler)). The handler is the generic `harbor.http.static`, so every user of it is affected.                                                                                                                             | checked                                                                                |
| F-FS-5   | **`stop` without persistence deletes the wrong files.** Media and main playlists are deleted by bare name, relative to the process's working directory: same-named files there are deleted, the output's own playlists stay ([files.md §7](files.md#7-cleanup-on-stop)).                                                                                                                                                                                                             | checked (decoys in the working directory deleted)                                      |
| F-LIFE-1 | **`stop` then `start` without persistence corrupts the playlist.** The closed-segment lists survive `stop` while numbering restarts at 1 ([operator.md §3.2](operator.md#32-stop)). Seen: `EXT-X-MEDIA-SEQUENCE` goes from 5 back to 2, with no discontinuity tag. Derived, not run: when the restart comes before the lists are full, evicting an old entry deletes the new live file that took its name. This path is taken every time a fallible source goes away and comes back. | checked (sequence); read only (deletion)                                               |
| F-FS-2   | **Init segments are never deleted.** Their recorded name is relative and is tested and deleted relative to the working directory ([files.md §5](files.md#5-retention)). One leaks per run, per restart, per resume; and a same-named file in the working directory could be deleted.                                                                                                                                                                                                 | checked (leaked `m_0.mp4` after resume and after `stop`)                               |
| F-FS-4   | **The open segment's file stays after `stop` without persistence.** It is published (a `created` event fires) and not deleted ([files.md §7](files.md#7-cleanup-on-stop)).                                                                                                                                                                                                                                                                                                           | checked                                                                                |
| F-FS-1   | **`perm` ignores the umask.** Files are set to exactly `perm`, `0666` by default: world-writable segments and playlists. The parameter's documentation says "up to umask" ([files.md §3](files.md#3-writing-a-file)).                                                                                                                                                                                                                                                                | checked (umask 022 → 0666)                                                             |
| F-PL-1   | **Position gaps change a segment's media sequence number.** An aborted segment and every resume skip a position number ([segmenting.md §8](segmenting.md#8-position-numbers)); since the media sequence is the first position minus one, a segment after the gap gets one number while an older segment heads the window and another after. RFC 8216 forbids that.                                                                                                                   | checked (resume: 6 then 8); read only (abort; the skipped test's expectations show it) |
| F-FS-3   | **Retention keeps one segment fewer than documented.** `B − 1` closed segments stay; with `segments_overhead` 1, a segment named by the published playlist is deleted before the rewrite ([files.md §5](files.md#5-retention)).                                                                                                                                                                                                                                                      | checked                                                                                |
| F-SEG-1  | **`segment_duration` below one frame** gives a zero grid step and a division by zero at every frame, retried every 2 s without end ([segmenting.md §1](segmenting.md#1-segment-duration-and-the-grid)).                                                                                                                                                                                                                                                                              | checked                                                                                |
| F-VAR-1  | **A missing bandwidth fails at runtime, forever.** It is found at the first segment close, not at construction, and takes the reopen path on every retry ([variants.md §3](variants.md#3-derived-properties)). Every frame-unit format hits it unless `bandwidth` is given. `%mp3` ABR without a mean bit rate raises a different, unhandled exception there.                                                                                                                        | checked (`%wav`); read only (ABR)                                                      |
| F-STOP-1 | **The final flush at `stop` is all or nothing.** The first exception ends it for every later variant, and is dropped without a log ([operator.md §3.2](operator.md#32-stop)).                                                                                                                                                                                                                                                                                                        | read only                                                                              |
| F-PER-1  | **The state file is written in place**, not atomically, and is skipped if a segment close fails during `stop`. A crash mid-write leaves invalid JSON; a skipped write leaves the next start fresh with old segments on disk ([persistence.md §3](persistence.md#3-saving)).                                                                                                                                                                                                          | read only                                                                              |
| F-PER-2  | **A failed non-strict restore is half applied and retried.** Fields already copied stay, the file is kept and read again at every start ([persistence.md §4](persistence.md#4-restoring)).                                                                                                                                                                                                                                                                                           | read only                                                                              |
| F-ERR-1  | **After an error, the next segment starts on arbitrary bytes.** The encoder is not reset and the new segment does not wait for a split point; it is marked discontinuous but can start mid-GOP or mid-packet ([operator.md §6](operator.md#6-errors-and-reopening)).                                                                                                                                                                                                                 | read only                                                                              |
| F-ID3-1  | **Packed-audio ID3 timestamps** are reduced modulo `2^33 − 1` instead of `2^33`, and the per-frame 90 kHz step is truncated, so the timestamp drifts when a frame is not a whole number of 90 kHz ticks ([encoder-packed-audio.md §7](encoder-packed-audio.md#7-insert_id3)).                                                                                                                                                                                                        | read only (the example's timestamp is exact at 0.04 s frames)                          |
| F-SRV-3  | **Content types**: `.ts` is served as `application/octet-stream`, `.m4s` with none; `extname` overrides are ignored; `%flac`'s MIME type is spelt `audio/flex` ([serving.md §3.1](serving.md#31-content-types)).                                                                                                                                                                                                                                                                     | checked (`.ts`, `.m4s`); read only (flac)                                              |
| F-SRV-2  | **`output.harbor.hls.https` never exists**: it is guarded on a function nothing defines ([serving.md §1](serving.md#1-entry-points)).                                                                                                                                                                                                                                                                                                                                                | checked                                                                                |
| F-TEST-1 | **The only discontinuity test is skipped**, and its expected bytes predate the current grid. The fMP4 ID3 check asserts a missing feature. ([conformance.md](conformance.md))                                                                                                                                                                                                                                                                                                        | checked                                                                                |

## Gaps

| Id       | Finding                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F-OWN-1  | The grid and cut rules are stated in the `%ffmpeg` encoder spec (§8.7), from the encoder's side, and cited from the output's code. The output's rules have no owner of their own; this spec now describes them, and the two texts must be made one ([segmenting.md](segmenting.md)).                                                                                                                                                                                          |
| F-GRID-1 | **Split points just after every boundary** give alternating long and short segments (4, 2, 4, 2 with 2 s key frames and 6 s segments) while every key frame is within 0.1 s of a boundary. The rule is applied as written ([segmenting.md §5.2](segmenting.md#52-worked-example)); nothing states a tolerance. Field report, KC3.                                                                                                                                             |
| F-GRID-2 | **Variants of one output drift apart in numbering.** Media time is the same for every variant, but split times come from each encoder's packets, which start at different offsets per variant; stub segments from F-GRID-1 give video variants more segments than an audio-only one (seen: media sequence 0 against 4). Nothing states that segment _n_ covers the same media time in every variant, which adaptive switching needs. Field report, KC4. Mechanism: read only. |
| F-VAR-2  | Reading `streams()` before a variant's init segment caches the format-derived properties for the rest of the run ([variants.md §3](variants.md#3-derived-properties)).                                                                                                                                                                                                                                                                                                        |
| F-PL-4   | The main playlist is written once; a container restart that changes codecs or size does not update it ([playlists.md §3](playlists.md#3-main-playlist)).                                                                                                                                                                                                                                                                                                                      |
| F-PL-2   | The `EXT-X-MAP` URI is quoted with the language's escapes; HLS quoted strings have none. Segment names with directories lose them in playlists ([playlists.md §2](playlists.md#2-media-playlist)).                                                                                                                                                                                                                                                                            |
| F-PER-3  | Persisted segment lengths are in ticks whose rate depends on unsaved settings; changing the audio rate or frame settings between runs rescales old `EXTINF`s ([persistence.md §2](persistence.md#2-format)).                                                                                                                                                                                                                                                                  |
| F-ENC-1  | Any encoder is accepted, including containers RFC 8216 does not list (WAV, Ogg, FLAC, AVI), with no warning ([encoder-frame-units.md](encoder-frame-units.md)).                                                                                                                                                                                                                                                                                                               |
| F-SRV-4  | The served directory exposes temporary files and, when it is there, the state file; with `tmpdir = null` the directory is new every run, so a relative `persist_at` never resumes ([serving.md §2](serving.md#2-composition)).                                                                                                                                                                                                                                                |
| F-ERR-2  | The default `reopen_on_error` retries every 2 s without limit, also for errors that cannot heal (F-SEG-1, F-VAR-1).                                                                                                                                                                                                                                                                                                                                                           |
| F-TAG-1  | Inserted tags are written in reverse insertion order and without any check that they are valid playlist lines ([metadata.md §3](metadata.md#3-inserted-tags)).                                                                                                                                                                                                                                                                                                                |
| F-STOP-2 | No `EXT-X-ENDLIST` at `stop`; and the encoder's final bytes become a stub segment of their own ([playlists.md §1](playlists.md#1-common-form), [persistence.md §2](persistence.md#2-format)).                                                                                                                                                                                                                                                                                 |
| F-TEST-2 | No test covers retention, deletion, cleanup, modes, the state bytes, sequence continuity, event paths, packed-audio ID3 bytes, serving, or stop/start without persistence ([conformance.md §6](conformance.md#6-not-covered)).                                                                                                                                                                                                                                                |

## To verify (claims about external systems, from memory)

- RFC 8216: a segment's media sequence number never changes (§6.2.1–6.2.2);
  `EXTINF` rounded to the nearest integer must not exceed the target
  duration (§4.3.3.1); packed-audio segments need the `PRIV` timestamp
  (§3.4) as a 33-bit value; `EXT-X-MAP` needs version 5, or 6 in some cases
  (§7); the registered media types are `application/vnd.apple.mpegurl` and
  `audio/mpegurl`, not `application/x-mpegURL`; MPEG-TS is `video/mp2t`.
- Players' handling of a media sequence that goes backwards without a
  discontinuity (F-LIFE-1): assumed to stall or skip; not tried.
- Whether `%ffmpeg` MPEG-TS writes an empty timed-ID3 packet at each segment
  that opens without metadata.

Nothing here was run against a CDN, a player or a browser. The serving
checks used `curl` against `127.0.0.1`.
