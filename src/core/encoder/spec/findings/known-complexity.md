# Findings from known complexity

Entries of [known-complexity.md](../known-complexity.md) whose reconciliation with
the as-built text is "Not covered" (the text is silent) or "Contradicts" (history
shows the described behaviour is a bug or was changed). Read only: drawn from
history, not re-run.

| Entry                           | Title                                                                               | Reconciliation                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [KC-1](../known-complexity.md)  | Ending a logical stream that received no data, or whose codec holds none            | Not covered / Contradicts. The behaviour is described ([ogg.md §5](../ogg.md#5-encode_metadata), [§9](../ogg.md#9-stop), [Ending a link](../ogg.md#ending-a-link), each codec's §10), and it is the defect: the leading skeleton-only link (§5) and the raising Theora stand-in (§9) are what history shows to be bugs. Missing: a rule that an instance never emits a link with no track and that the empty-track case produces a valid end with the codec's own channel count. |
| [KC-2](../known-complexity.md)  | Draining at `stop`: the encoder's queue, the codec's look-ahead, the resampler      | Contradicts [draining.md §2, §4](../../../source/spec/draining.md#2-the-rule): [mp3.md §9](../mp3.md#9-stop), [shine.md §9](../shine.md#9-stop), [fdkaac.md §9](../fdkaac.md#9-stop), [ogg.md §9](../ogg.md#9-stop) describe the losses as the behaviour; history and the draining rule make them defects.                                                                                                                                                                       |
| [KC-3](../known-complexity.md)  | Encoder delay and padding are not signalled                                         | Not covered. [ogg-opus.md §3, §10](../ogg-opus.md#10-end-of-stream) and [mp3.md §9](../mp3.md#9-stop) state the values; the as-built has no requirement that delay and padding be signalled, nor a section for it in the encoder numbering ([encoder.md §8](../encoder.md#8-section-numbering-of-implementation-files)).                                                                                                                                                         |
| [KC-4](../known-complexity.md)  | A new link at every metadata change, and the consumers that cannot follow           | Covered for the behaviour ([ogg.md §5](../ogg.md#5-encode_metadata), [§13 item 7](../ogg.md#13-where-the-bytes-go)): every metadata change, even empty or identical, makes a link. Not covered: no option to carry metadata out of band only (asked in #5306), and no statement of what a consumer is promised across a link boundary.                                                                                                                                           |
| [KC-5](../known-complexity.md)  | `header` and `restart_offset` must be right at every moment, for every encoder      | Covered as built ([encoder.md §3.4, §3.5](../encoder.md#34-header), [ogg.md §6, §7, §13 items 2–3](../ogg.md#6-header)). Not covered: `header` for native FLAC and `%external`, `restart_offset` for a process restart, and `header` between `encode_metadata` and the next `encode`; the old normative "complete at every moment" is contradicted by the code ([encoder.md §10](../encoder.md#10-the-previous-normative-text-against-the-code)).                                |
| [KC-6](../known-complexity.md)  | Interleaving and page completion hold bytes for an unbounded time                   | Covered as built ([ogg.md Interleaving](../ogg.md#interleaving), [Page sizing](../ogg.md#page-sizing), [§13 item 5](../ogg.md#13-where-the-bytes-go)). Not covered: no latency bound exists, and the page-fill parameter meant to bound it has no effect (KC-18).                                                                                                                                                                                                                |
| [KC-7](../known-complexity.md)  | A library's output callback is not a framing unit                                   | Not covered. [ogg-flac.md §2, §8](../ogg-flac.md#8-packets-granule-positions-and-pages) speak of "pages" handed over; the invariant that the host must frame by content, not by callback count, is only in the language notes.                                                                                                                                                                                                                                                   |
| [KC-9](../known-complexity.md)  | The external process: start, end of output, restart, stop                           | Covered as built ([external.md §9, §10, §11](../external.md#9-stop)). Contradicts the old normative "`stop` drains and returns final bytes" ([encoder.md §10](../encoder.md#10-the-previous-normative-text-against-the-code)). Not covered: restarts as stream starts (KC-5), signalling of dropped input.                                                                                                                                                                       |
| [KC-10](../known-complexity.md) | When a configuration error surfaces, and what it says                               | Covered as built ([formats.md §4, §5](../formats.md#4-evaluation-building-the-format-value), [encoder.md §2.3](../encoder.md#23-instance-creation)). Not covered: no single point where a format is known valid, and no rule against silent library rejection.                                                                                                                                                                                                                   |
| [KC-12](../known-complexity.md) | Defaults that depend on settings the script sets later                              | Covered ([formats.md §5](../formats.md#5-deferred-values)). | [KC-14](../known-complexity.md) | Rate conversion inside the encoder                                                  | Not covered: the as-built mentions the converter per encoder; no common description of it as a stage with a tail.                                                                                                                                                                                                                                                                                                                                                                |
| [KC-15](../known-complexity.md) | Metadata in the bytes: which values, when, and in what form                         | Covered as built ([encoder.md §2.3](../encoder.md#23-instance-creation), [mp3.md §10.2](../mp3.md#102-id3v2-tag)). | [KC-16](../known-complexity.md) | Headers that describe the whole stream, on a destination that cannot seek back      | Covered as built ([wav.md §13](../wav.md#13-where-the-bytes-go), [flac.md §13](../flac.md#13-where-the-bytes-go), [encoder.md §7](../encoder.md#7-where-the-bytes-go-what-the-seam-assumes)).
