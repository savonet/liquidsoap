## Confirmed defects ranked by severity

Data loss and stopped outputs first, then wrong results, then cosmetics.

1. **ogg D3**: `%ogg(%theora)` fails the whole output (`Theora.Invalid_data`) when a link ends with no video image. Reproduced with dense metadata.
2. **ogg D1**: Opus drops 3528 samples (73.5 ms) at the start of every link, so at every metadata change.
3. **simple 1**: an `%external` process that exits early loses its buffered output and fails the clock.
4. **simple 2**: `%external(restart_on_crash=true)` fails the clock on EPIPE.
5. **native 7**: a `%flac` that libFLAC rejects writes 0 bytes, with exit 0 and no log.
6. **native 1**: `%fdkaac` never emits its tail: 5672 samples lost per stop with HE-AAC v2, 1639 with LC.
7. **simple 4**: `%external(restart_on_metadata)` drops about 80 ms per restart. The clock-failure window is read only.
8. **ogg D9**: AV Ogg files start with a skeleton-only link, and ffprobe cannot identify the first stream.
9. **native 2, native 3, native 4, ogg D2**: tails are dropped at stop.
   - LAME: the generator remainder (484 samples).
   - shine: 1544 samples.
   - Resamplers are never drained.
   - Opus and Speex drop their frame remainder and end with an empty EOS page at gp+1.
10. **native 9**: the ID3v2 and FLAC comments are always empty for `output.file`, because `current_metadata` is never set.
11. **native 6**: `%flac` STREAMINFO has no sample count or MD5, so the file has no duration and cannot be seeked.
12. **simple 5, simple 6, simple 7**: `%avi` writes wrong chunks.
    - Several images go in one chunk, and empty chunks are written.
    - Liquidsoap cannot read its own AVI.
    - Odd sizes disagree with the header.
13. **native 5**: the `%flac` stream header is missing from `header()`.
14. **native 12**: icecast always drops the encoder's stop bytes, and `output.file` drops them when `stop` raises.
15. **simple 8**: `%wav(duration)` declares a length that nothing enforces.
16. **ogg D6**: `%vorbis.abr` with default settings fails at start.
17. **simple 3**: `restart_after_delay` is a documented no-op.
18. **ogg D5**: `bytes_per_page` is a no-op.
19. **simple 9**: NDI timecodes run 0.33 % slow at 44.1 kHz.
20. **seam D1, seam D2, simple 10, native 11, simple 11**: the typer and the builder disagree. Scripts that pass `--check` fail at run time, or a valid value is rejected, often with no position.
21. **seam D3, ogg D7**: some format values crash the type checker with `Audio_layout.Unsupported`.
22. **seam D4**: `==` on encoder formats raises.
23. **seam D10**: a missing Ogg sub-encoder is detected only at instance creation, and a missing Theora raises `Option.get`. This was read only.
24. **ogg D10**: `header()` is incomplete in the link-change window. This was read only, and the race is narrow.
25. **native 10**: `id3v2=n` is unchecked, and `n=2` gives an invalid layout.
26. **seam D8, native 8**: the FLAC MIME type is `audio/flex`, which is wrong on the wire.
27. **ogg D4**: the empty-link fallback uses the frame's channel count. This is latent.
28. **ogg D11**: the `Hashtbl` is modified while it is being iterated. This is latent.
29. **seam D6**: error 12 can never be raised.
30. Cosmetic:
    - seam D5, seam D9 and ogg D8: printed forms that do not parse back.
    - seam D7 and simple 12: `%%` appears in NDI messages.
    - ogg D12: the Opus bitrate message gives the wrong range.
