Module Liquidsoap_ffmpeg_formats_dummy.Standin

The stand-in parameters of the FFmpeg content kinds (content.md §10): the (label, value) pairs a script wrote, checked as the libav parameters are, with no data operations. Linking this module registers the kinds; only a process that cannot stream links it.
