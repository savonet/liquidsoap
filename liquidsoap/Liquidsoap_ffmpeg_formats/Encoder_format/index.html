Module Liquidsoap_ffmpeg_formats.Encoder_format

The %ffmpeg(...) format record (encoder-format.md §1), and what follows from it without libav: track names (§2), media types (§2.1), the channel rule (§5), the content type (§10), rendering (§11), extension and MIME (§12).

The type checker (Encoder_typing) and the runtime parser (libav side) both reduce a format to a list of shapes and type it with fields_type, so the type a script is checked against is the type the encoder is given. What needs libav reaches this module through lookups, which the libav side fills and a process without it leaves at its fallback.
