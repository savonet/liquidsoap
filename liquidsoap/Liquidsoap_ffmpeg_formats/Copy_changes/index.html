type form = [
  1. | `Annex_b
  2. | `Length_prefixed
  3. | `Adts
  4. | `Raw_aac
  5. | `Other
]

The form a codec's configuration travels in: inside the stream (`Annex_b H.264 or HEVC, `Adts AAC) or in the codec parameters alone (`Length_prefixed, `Raw_aac); `Other for codecs with a single form.

val form_name : form -> string

The name copy parameters print for a form.

type container = [
  1. | `Named of string
  2. | `Unknown
]

A muxer name, or `Unknown for a %ffmpeg format without a literal format.

type t = container list

The containers the encoders of a copied track write (content.md §3.1.1). The encoder typing sets them from a %ffmpeg format (of_container), a merge takes the union, and a source may change only what every one of them allows (allowed). An empty list is a track no encoder constrains: nothing may change.

containers=mpegts+matroska, ? for an unknown container; empty for no container.

The containers value of an ffmpeg.copy type, as to_string prints it.

val rule : container:container -> codec:string -> form:form -> property -> [ `In_band | `Restart | `No ]

What container does when a source of this codec and bitstream form changes property: carries the change in the stream (`In_band), follows it with a new container (`Restart, Ogg chaining, which the encoder does for stream and file outputs only), or cannot (`No). A user-visible property or a codec header changes only where the table lists it, as its conformance tests decode; block align, which users do not see, changes anywhere and FFmpeg judges it (content.md §3.1.1).

val allowed : t -> codec:string -> form:form -> property -> bool

Every container of t follows a change of property.
