One entry as a frame holds it: its kind and a copy of its payload. The record is private: an entry comes from Frame.side_data or from encode, never from arbitrary bytes, because FFmpeg reads a payload at the size its kind implies. For most kinds the payload is a C structure of the FFmpeg build in use: it must not be stored or sent to another process.

type t = [
  1. | `Display_matrix of Display_matrix.t
]

The kinds whose content the bindings translate.

val name : kind -> string

FFmpeg's name of the kind, empty when it has none.

val props : kind -> prop list

The properties FFmpeg gives the kind, such as `Global for a kind that applies to a whole stream.

val decode : raw -> t option

The content of an entry. None for a kind outside t and for a payload too short for its kind.

val encode : t -> raw

The entry holding a content. decode (encode d) is Some d.

val display_matrix : raw list -> Display_matrix.t option

The matrix of the first entry that holds one.
